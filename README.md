# agent-foundry
Agent Foundry project repository. Coordination records live in the team's shared workspace (COORDINATION.md, BOARD.md, HANDOFFS.md).

CI runs on every pull request and push to `main` (`.github/workflows/ci.yml`).

## Contributing
See [CONTRIBUTING.md](CONTRIBUTING.md). Branch protection on `main` requires a PR, a passing `ci` check and 1 approving review.
